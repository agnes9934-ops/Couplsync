# 쿠플 싱크

쿠팡플레이를 각자 자기 기기에서 재생하면서 **재생, 일시정지, 이동을 서로 맞추고 댓글을 주고받는** 도구입니다.
영상은 각자 계정으로 재생하므로 화질 저하나 DRM 검은 화면이 없습니다.

| 폴더 | 내용 |
|---|---|
| `android/` | 안드로이드 앱. 쿠팡플레이 앱 재생을 자동으로 맞추고, 화면 위 채팅 버블 제공 |
| `extension/` | PC 크롬 확장 프로그램 (같은 방에 함께 접속 가능) |
| `server/` | 동기화 중계 서버 (한 곳에만 띄우면 됨) |

---

## 준비 1. 서버 띄우기 (한 번만, 무료)

PC에서 하는 게 편합니다.

1. [github.com](https://github.com)에 가입하고 **New repository**로 새 저장소를 만듭니다. (Private 가능)
2. 이 zip 파일을 그대로 업로드합니다. (압축은 GitHub이 자동으로 풉니다)
3. [render.com](https://render.com)에 GitHub 계정으로 가입 → **New → Blueprint** → 방금 만든 저장소 선택 → Apply.
   `render.yaml` 설정대로 서버가 자동으로 만들어집니다.
4. 생성된 주소(예: `https://couplsync-server-xxxx.onrender.com`)를 브라우저로 열어 "정상 작동 중"이 보이면 성공.
5. 앱에 넣을 서버 주소는 `https`를 `wss`로 바꾼 것입니다: `wss://couplsync-server-xxxx.onrender.com`

> Render 무료 플랜은 15분간 아무도 접속하지 않으면 잠들고, 다시 깨우는 데 30초~1분 걸립니다.
> 볼 때 서버 주소를 브라우저로 한 번 열어서 깨운 뒤 연결하세요.

## 준비 2. 앱 설치 파일(APK) 만들기

GitHub 저장소에 이 zip과 함께 `.github/workflows/build.yml`(Claude가 안내한 내용)을 올리면
GitHub이 자동으로 압축을 풀고 앱을 빌드해서, 저장소의 **Releases**에 `couplsync.apk`를 올려 줍니다.

## 준비 3. 폰에 설치 (두 분 모두)

1. `app-debug.apk`를 카톡 나에게 보내기 등으로 폰에 옮겨 실행합니다.
2. "출처를 알 수 없는 앱 설치" 허용 안내가 나오면 허용합니다.
3. Play 프로텍트 경고가 뜨면 "무시하고 설치"를 선택합니다. (직접 만든 앱이라 서명이 등록되지 않아서 뜨는 경고입니다)

## 사용 방법

1. **쿠플 싱크** 앱 실행
2. ① 권한 2개 허용
   - **알림 접근**: 다른 앱의 재생을 제어하는 데 필요 (안드로이드 13 이상에서 "제한된 설정" 때문에 회색으로 막혀 있으면:
     설정 → 애플리케이션 → 쿠플 싱크 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 시도)
   - **다른 앱 위에 표시**: 쿠팡플레이 화면 위에 채팅 버블을 띄우는 데 필요
3. ② 서버 주소, **같은 방 코드**, 닉네임 입력 → **연결**
4. ③ **쿠팡플레이 열기** → 같은 콘텐츠 재생
5. 한 사람이 재생/일시정지/이동하면 다른 사람 폰도 따라갑니다.
6. 화면의 💬 버블을 누르면 댓글 입력창이 열립니다. 받은 댓글은 버블 위에 잠깐 뜹니다. 버블은 끌어서 옮길 수 있습니다.
7. 끝나면 앱의 **해제** 또는 알림창의 **연결 해제**

PC 크롬 확장 프로그램(`extension/`)도 같은 서버 주소·방 코드로 접속하면 함께 볼 수 있습니다.

## 잘 안 될 때

앱 ③ 아래에 진단 정보가 표시됩니다.

- **"쿠팡플레이 재생 세션 없음"**: 쿠팡플레이에서 영상을 실제로 재생 중인지 확인하세요.
  그래도 안 뜨면 쿠팡플레이 앱이 재생 제어 통로(MediaSession)를 열어두지 않은 것이라, 자동 동기화는 불가능하고 채팅만 됩니다.
  (괄호 안에 "감지된 앱" 목록이 나오면 그 이름을 알려주세요)
- **지원 기능에 "이동"이 없음**: 재생/정지만 맞춰지고 위치 이동은 맞춰지지 않습니다.
- **연결 실패**: 서버 주소가 `wss://`로 시작하는지, 서버가 잠들어 있지 않은지 확인하세요.

## 한계

- **쿠팡플레이 앱에서 실제로 테스트하지 못했습니다.** 쿠팡플레이 앱이 외부 재생 제어를 받아들이는지가 관건입니다.
- 실시간 스포츠 중계는 이동이 없어서 사실상 채팅 용도입니다.
- 방 코드가 곧 비밀번호입니다. 추측하기 어려운 코드를 쓰세요.
